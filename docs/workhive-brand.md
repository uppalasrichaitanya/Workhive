# Workhive brand

Workhive combines a small honeycomb of job listings with a negative-space W. The mark uses flat blocks so it remains legible at favicon size and does not depend on gradients, shadows, or glow effects.

## Assets

- \`public/workhive-mark.svg\` is the color icon-only mark for 32px to 512px contexts.
- \`public/workhive-lockup.svg\` is the horizontal icon + lowercase wordmark lockup with \`JOB AGGREGATOR\`.
- \`public/workhive-mark-mono.svg\` is the single-color mark for watermarks, print, and constrained app-icon contexts.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Workhive coral | \`#E45D36\` | Primary accent and brand background |
| Hive ember | \`#D94A2B\` | Dark supporting cell |
| Hive amber | \`#FF9B4A\` | Light supporting cell |
| Graphite | \`#20252B\` | Monochrome mark and wordmark |

The application uses Workhive coral as its single strong accent and keeps the interface graphite, white, and muted gray.
